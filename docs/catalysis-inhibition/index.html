그래프는 자유 입자의 병진 운동 에너지 분포입니다. 위쪽에서 온도를 바꾸면 곡선이 이동합니다. 조건 ②·④를 선택하면 같은 곡선에 낮은 장벽 기준선이 추가됩니다. 기준선 너머 입자의 비율과 실제 반응 속도 사이에는 충돌 방향·활성점 수 등의 조건도 작용합니다.

모형 가정과 용어

정촉매는 반응 과정에 참여하고 재생됩니다. 여기서 ‘부촉매’는 반응 속도를 감소시키는 억제제를 가리킵니다. IUPAC는 inhibitor라는 용어를 권합니다. 두 억제 모형은 각각 과량의 억제제가 자유 반응물 또는 촉매 활성점에 빠르게 가역 결합한다고 가정합니다. 사슬 반응 중간체를 제거하는 억제제 등은 다른 메커니즘을 따릅니다.

관찰 구간에서 역반응을 무시한 유사 1차 모형이며 [P](t) = [A]₀(1 − exp(−k관측 t))입니다. 무첨가 경로와 열린 촉매 경로의 속도 상수는 300 K에서 각각 0.020, 0.080 s⁻¹입니다. 온도에 따른 변화는 각 경로의 모형 활성화 에너지(40, 24 kJ/mol)로 계산합니다. 온도를 비교할 때 Kᵦ[I]는 지정한 값으로 고정합니다. 선택한 발열·흡열 예시에서 각 경로의 출발·도착 엔탈피는 같습니다. 정방향 장벽과 속도 상수는 유지하고 생성물의 엔탈피만 바꿔 비교합니다.
