# 과학 시뮬레이터

GitHub Pages용 단일 HTML 시뮬레이터 9종과 기존 공개 시뮬레이터 3종을 연결하는 수업 자료 목록입니다.

로컬에서 `docs/index.html`을 열어 목록을 확인합니다. 각 시뮬레이터는 개별 폴더의 `index.html`로도 열 수 있습니다.

## 게시할 때

준비한 저장소 이름은 `science-simulators`입니다. 게시 전 실제 전송할 파일과 Git 이력의 개인정보 및 비밀정보를 검사합니다. GitHub Pages에서 브랜치 게시를 선택하고 게시 폴더를 `/docs`로 설정합니다. 새 주소는 `https://mananin42.github.io/science-simulators/<폴더명>/` 형식입니다. 저장소 이름이나 소유자가 바뀌면 등록용 CSV의 새 주소 9개를 함께 갱신합니다. 배포된 주소를 확인한 뒤 구글시트에 등록합니다.

Chem-Screen의 작업 원본은 같은 분류의 `chem-screen-drug-candidate-simulator` 프로젝트에서 관리합니다. 갱신할 때 해당 HTML을 `docs/chem-screen/index.html`에 반영합니다. 아스피린 결합 절단 페이지의 하단 링크는 이 모음의 첫 화면을 가리킵니다.
